# Fluent Emoji licence and attribution (style board)

`style_board.png` in this folder is a 3x3 grid composed by
`backend/scripts/icon_style_spike.py board` from nine images of Microsoft's **Fluent Emoji**
"3D" set, <https://github.com/microsoft/fluentui-emoji>, downloaded 2026-10-06 from the
`main` branch. The images were scaled down and placed on a white background; they were not
otherwise changed. No Apple emoji image was used.

Source files (paths inside the repository, grid order left to right, top to bottom):

1. `assets/Tomato/3D/tomato_3d.png`
2. `assets/Carrot/3D/carrot_3d.png`
3. `assets/Cheese wedge/3D/cheese_wedge_3d.png`
4. `assets/Bread/3D/bread_3d.png`
5. `assets/Canned food/3D/canned_food_3d.png`
6. `assets/Glass of milk/3D/glass_of_milk_3d.png`
7. `assets/Red apple/3D/red_apple_3d.png`
8. `assets/Broccoli/3D/broccoli_3d.png`
9. `assets/Egg/3D/egg_3d.png`

The board is used only as an IP-Adapter style reference for the Q18-S2 spike renders.
