usage: kyokki shopping export [-h] [--format {text,markdown}] [--url URL]
                              [--token TOKEN] [--json] [--verbose]

Print the open list, urgent first and then by name, exactly as the
server renders it: text is '- name amount unit' per line, markdown a
'- [ ] name (amount unit)' checklist. The body is written as it is,
also when stdout is a file or a pipe; JSON ({"format": ..., "text":
...}) only with --json.

options:
  -h, --help            show this help message and exit
  --format {text,markdown}
                        text or markdown; default: text

connection and output:
  --url URL             Kyokki base URL, e.g. http://kyokki.lan:17300
                        (default: $KYOKKI_URL)
  --token TOKEN         API token, sent as a Bearer header and never printed
                        (default: $KYOKKI_TOKEN)
  --json                print JSON: the API's answer, or an error's detail
                        object (the default when stdout is not a terminal)
  --verbose             log each request and its status to stderr

examples:
  kyokki shopping export
  kyokki shopping export --format markdown > list.md
  kyokki shopping export --json

exit codes:
  0 ok
  1 error: cannot reach the server, a 5xx, an answer that is not text/plain or
    text/markdown
  2 usage: bad arguments, or the API rejected the request (400 invalid, 422)
  3 not found: does not occur for this command
  4 ambiguous name: does not occur for this command
  5 insufficient stock: does not occur for this command
  6 conflict: does not occur for this command
  7 auth: missing or unknown token (401), or a read token on a write (403)
