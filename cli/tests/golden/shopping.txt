usage: kyokki shopping [-h] COMMAND ...

The shopping list: open items, adding and ticking them off, filling
it from low stock, and exporting it as text.

options:
  -h, --help  show this help message and exit

commands:
  COMMAND
    list      the open items, urgent first
    add       put an item on the list
    done      tick an item off as bought (or back on with --undo)
    remove    delete an item from the list
    generate  put what the kitchen is short of on the list
    export    the open list as plain text or a Markdown checklist

examples:
  kyokki shopping list
  kyokki shopping add milk 1 l --priority urgent
  kyokki shopping generate --dry-run

exit codes:
  0 ok
  1 error: cannot reach the server, a 5xx, an answer that is not the expected
    JSON (or text, for export), or a change sent that got no answer (it may have
    been applied)
  2 usage: bad arguments, or the API rejected the request (400 invalid, 422)
  3 not found: no shopping item has the ID (done, remove), or no product has the
    --product-id (add)
  4 ambiguous name: does not occur for this command
  5 insufficient stock: does not occur for this command
  6 conflict: a reused Idempotency-Key (409) (add, done, generate)
  7 auth: missing or unknown token (401), or a read token on a write (403)
