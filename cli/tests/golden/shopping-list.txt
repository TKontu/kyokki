usage: kyokki shopping list [-h] [--all] [--priority {urgent,normal,low}]
                            [--url URL] [--token TOKEN] [--json] [--verbose]

The open (not yet bought) items, urgent first. --all adds the ones
already bought. The ID column is what done and remove take. It shows
every item: the CLI asks for pages of 500 until the list runs out.

options:
  -h, --help            show this help message and exit
  --all                 include items already bought
  --priority {urgent,normal,low}
                        only items of this priority

connection and output:
  --url URL             Kyokki base URL, e.g. http://kyokki.lan:17300
                        (default: $KYOKKI_URL)
  --token TOKEN         API token, sent as a Bearer header and never printed
                        (default: $KYOKKI_TOKEN)
  --json                print JSON: the API's answer, or an error's detail
                        object (the default when stdout is not a terminal)
  --verbose             log each request and its status to stderr

examples:
  kyokki shopping list
  kyokki shopping list --priority urgent
  kyokki shopping list --all --json

exit codes:
  0 ok
  1 error: cannot reach the server, a 5xx, an answer that is not the expected
    JSON
  2 usage: bad arguments, or the API rejected the request (400 invalid, 422)
  3 not found: does not occur for this command
  4 ambiguous name: does not occur for this command
  5 insufficient stock: does not occur for this command
  6 conflict: does not occur for this command
  7 auth: missing or unknown token (401), or a read token on a write (403)
