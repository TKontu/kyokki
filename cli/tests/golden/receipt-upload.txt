usage: kyokki receipt upload [-h] [--wait] [--timeout SECONDS] [--url URL]
                             [--token TOKEN] [--json] [--verbose]
                             FILE

Upload FILE (an image or PDF) for OCR and extraction, which runs
in the background. Prints the new receipt's id and status. With --wait,
polls kyokki receipt status every few seconds (bounded by --timeout,
default 1800 s: a receipt can take up to ~30 minutes when the model
re-reads it) until the read finishes, then prints the lines. A file that
cannot be read, or is over the server's upload limit (413), is exit 2
before anything is sent; a duplicate (the server already has this file)
is exit 6, with the existing receipt's id. Like scan itself, upload sends
no Idempotency-Key; a retried upload of the same file answers the same
409 duplicate.

positional arguments:
  FILE               path to the receipt image or PDF

options:
  -h, --help         show this help message and exit
  --wait             poll until the read finishes, then print the lines
  --timeout SECONDS  give up waiting after this long; default: 1800 (needs
                     --wait)

connection and output:
  --url URL          Kyokki base URL, e.g. http://kyokki.lan:17300 (default:
                     $KYOKKI_URL)
  --token TOKEN      API token, sent as a Bearer header and never printed
                     (default: $KYOKKI_TOKEN)
  --json             print JSON: the API's answer, or an error's detail object
                     (the default when stdout is not a terminal)
  --verbose          log each request and its status to stderr

examples:
  kyokki receipt upload receipt.jpg
  kyokki receipt upload receipt.pdf --wait
  kyokki receipt upload receipt.jpg --wait --timeout 120

exit codes:
  0 ok
  1 error: cannot reach the server, a 5xx, an answer that is not JSON, or a
    change sent that got no answer (it may have been applied)
  2 usage: bad arguments, or the file cannot be read, it is over the server's
    upload limit (413), or the API rejected it (400 invalid, 422)
  3 not found: does not occur for this command
  4 ambiguous name: does not occur for this command
  5 insufficient stock: does not occur for this command
  6 conflict: the file was already uploaded (409); the message names the
    existing receipt id
  7 auth: missing or unknown token (401), or a read token on a write (403)
