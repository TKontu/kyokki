usage: kyokki shopping add [-h] [--priority {urgent,normal,low}]
                           [--product-id UUID] [--idempotency-key KEY]
                           [--url URL] [--token TOKEN] [--json] [--verbose]
                           NAME [AMOUNT] [UNIT]

Put NAME on the shopping list. NAME is free text and must not be
blank. AMOUNT and UNIT go together; without --product-id they may be
left out, and the item is 1 pcs.

--product-id links the item to a product, so generate raises this item
instead of adding a second one. --product-id needs AMOUNT UNIT, in the
product's unit: generate skips a linked item it cannot count in that
unit. Options may come anywhere, also between NAME and AMOUNT.

positional arguments:
  NAME                  what to buy, as it should read
  AMOUNT                how much, in UNIT (a number above 0); default: 1 pcs,
                        and required with --product-id
  UNIT                  dl, tsp, tbsp, g, pcs (l, ml, kg and the like are
                        converted by the server); needs AMOUNT

options:
  -h, --help            show this help message and exit
  --priority {urgent,normal,low}
                        how badly it is needed; default: normal
  --product-id UUID     the product it is (a UUID), from product resolve;
                        needs AMOUNT UNIT
  --idempotency-key KEY
                        retry key (at most 255 characters); default: SHA-256
                        of this command line and the UTC minute, so a retry
                        within the minute is safe

connection and output:
  --url URL             Kyokki base URL, e.g. http://kyokki.lan:17300
                        (default: $KYOKKI_URL)
  --token TOKEN         API token, sent as a Bearer header and never printed
                        (default: $KYOKKI_TOKEN)
  --json                print JSON: the API's answer, or an error's detail
                        object (the default when stdout is not a terminal)
  --verbose             log each request and its status to stderr

examples:
  kyokki shopping add milk 1 l --priority urgent
  kyokki shopping add 'dish soap'
  kyokki shopping add eggs 12 pcs --product-id 0b6f7a3e-8d4c-4a53-9d1e-2f6c1b7e9a01

exit codes:
  0 ok
  1 error: cannot reach the server, a 5xx, an answer that is not JSON, or a
    change sent that got no answer (it may have been applied)
  2 usage: bad arguments, or the API rejected the request (400 invalid, 422)
  3 not found: no product has the --product-id
  4 ambiguous name: does not occur for this command
  5 insufficient stock: does not occur for this command
  6 conflict: a reused Idempotency-Key (409)
  7 auth: missing or unknown token (401), or a read token on a write (403)
