usage: kyokki stock runout [-h] [--within DAYS] [--include-out] [--url URL]
                           [--token TOKEN] [--json] [--verbose]

A daily use rate from the last 60 days of consumption (no
seasonality), and the date active stock runs out at that rate. A
product without enough history reports insufficient_history. One
already out of stock reports out, but is left off the list by
default - this answers what will run out soon, not what is gone -
unless --include-out is given. Writes nothing.

options:
  -h, --help     show this help message and exit
  --within DAYS  only products running out within DAYS days
  --include-out  also list products already out of stock

connection and output:
  --url URL      Kyokki base URL, e.g. http://kyokki.lan:17300 (default:
                 $KYOKKI_URL)
  --token TOKEN  API token, sent as a Bearer header and never printed
                 (default: $KYOKKI_TOKEN)
  --json         print JSON: the API's answer, or an error's detail object
                 (the default when stdout is not a terminal)
  --verbose      log each request and its status to stderr

examples:
  kyokki stock runout
  kyokki stock runout --within 7
  kyokki stock runout --include-out

exit codes:
  0 ok
  1 error: cannot reach the server, a 5xx, an answer that is not the expected
    JSON, or a change sent that got no answer (it may have been applied)
  2 usage: bad arguments, or the API rejected the request (400 invalid, 422)
  3 not found: nothing matches the name, or no product has the id
  4 ambiguous name: the candidates are printed on stdout
  5 insufficient stock
  6 conflict: the name belongs to another product, or a reused Idempotency-Key
  7 auth: missing or unknown token (401), or a read token on a write (403)
